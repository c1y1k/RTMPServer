# 该目录下存储的是RTMP服务器的业务层模块，包含RTMP连接模块和各个解析子模块，chunk解析、消息组装、消息分发、消息处理。

## RTMP连接模块
### 两层状态树

  RTMPConn
  │
  ├─ 1. 握手阶段
  │    ├─ 等待 C0C1
  │    └─ 等待 C2
  │
  ├─ 2. 连接阶段
  │    ├─ 等待 connect
  │    └─ 等待 createStream
  │
  ├─ 3. 流工作阶段
  │    ├─ 等待 publish 或 play
  │    ├─ 推流中 Publishing
  │    └─ 拉流中 Playing
  │
  └─ 4. 结束阶段
       ├─ 关闭中 Closing
       └─ 已关闭 Closed
### rtmp_conn设计
该模块需要实现的功能有，读取tcp缓冲区、通过状态机握手、建立RTMP连接、建立流、结束，建立流后调用各个子模块进行处理，完成所有处理后结束。
